问题（Question）

面试官会问：“world prediction 和 value estimation 为什么会帮助 action imitation？什么时候反而会干扰 policy？多目标梯度如何共享视觉表征，又如何通过 mask/routing 避免互相污染？”

短答案

可直接口述：action imitation 只告诉模型“专家此刻做了什么”，world prediction 迫使视觉表征保留动作后果和环境动态，value estimation 让表征关注哪些状态更接近成功。因此三者共享视觉 encoder 时，world/value 可以给 action head 提供更有规划含义的表示。但它们也可能干扰 policy：如果 world loss 权重过大，表征会偏向像素/未来预测而不是可控动作；如果 value label 噪声大，可能把错误成功先验传给 policy；如果 routing 错，把 world/value 样本也拿去算 action loss，就会污染动作监督。所以项目关键是通过 world/value mask 互斥和 demo/world/value slot routing 控制每类样本只更新对应目标，同时共享底层视觉表示。

辅助目标为什么可能帮助 Action Imitation

目标学到的信号如何帮助 action可能干扰
Action imitation 专家动作分布 \(p(a_t|o_t,c)\) 直接训练 policy 输出 容易学到短视 repeat 或数据偏置
World prediction 动作后果、未来观测、环境动态 让视觉表征包含“做这个动作后会发生什么” 权重过大时会偏向预测视觉细节，降低动作判别性
Value estimation 状态到成功/回报的可达性 让表征关注任务进展和成功相关特征 value label 噪声会误导 policy

一个简化训练目标可以写为：

\[ \mathcal{L} = \lambda_a m_a \mathcal{L}_{action} + \lambda_w m_w \mathcal{L}_{world} + \lambda_v m_v \mathcal{L}_{value} \]

其中 \(m_a,m_w,m_v\) 是样本级或 slot 级 mask，\(\lambda_a,\lambda_w,\lambda_v\) 是损失权重。关键不是公式本身，而是 mask/routing 决定“哪个样本更新哪个 head”。本项目简历中对应的是 action/world/value 三目标、world/value mask 互斥、demo/world/value slot routing。

Mask / Routing 如何避免互相污染

def wam_training_step(batch, model):
    # batch.type 决定该样本是 demo/action、world prediction 还是 value estimation。
    z = model.visual_encoder(batch.images)

    # 三个 head 共享视觉表征，但 loss 由 routing 控制。
    pred_action = model.action_head(z)
    pred_world = model.world_head(z)
    pred_value = model.value_head(z)

    # mask 保证每类样本只对目标 head 产生梯度。
    action_loss = batch.m_action * mse(pred_action, batch.actions)
    world_loss = batch.m_world * world_objective(pred_world, batch.future)
    value_loss = batch.m_value * mse(pred_value, batch.value)

    # world/value mask 互斥，避免同一 slot 同时承载冲突语义。
    loss = wa * action_loss + ww * world_loss + wv * value_loss
    return loss

面试中可以说：“共享的是视觉 encoder，隔离的是目标 head 和 loss route。”这比“我复现了三目标训练”更能体现算法理解。

5. 2-3 分钟口述稿

Cosmos/WAM 这个项目我主要关注多目标后训练为什么能改善机器人 policy 表征。action imitation 直接学专家动作，但容易依赖短视 repeat 先验；world prediction 让视觉表征理解动作后果，value estimation 让表征关注任务是否接近成功。因此三者共享视觉 encoder 有潜在互补性。但辅助目标也可能污染 policy，比如 world loss 过大导致表征偏向预测视觉细节，value label 噪声会误导动作。我的工作是复现 RoboCasa recipe，并重点梳理 world/value mask 互斥、demo/world/value slot routing 和损失权重，使三类样本共享底层表示但只更新对应 head。结果上，held-out policy MSE 从 first-action-repeat baseline 的 0.09718 降到 0.05349，降低约 45%。同时我按官方 RoboCasa eval 复现 kitchen24，短时序开关门任务 0.90-0.95，抓取/放置代表任务 0.75；对低成功任务的分析指向长 horizon pick-and-place、world sample mask 和 value head 的后续改造。

追问树与回答分层

问题危险回答可过回答强回答
“world/value 为什么会帮 action？” 多任务训练一般会更好。 它们提供辅助监督。 world 提供动作后果建模，value 提供任务进展信号；二者改善共享视觉表征，但必须通过 mask/routing 控制梯度。
“什么时候会干扰？” 一般不会。 权重不合适会干扰。 world 权重过大、value label 噪声、样本 routing 错误、slot 语义冲突都会污染 action head。
“MSE 降了为什么成功率不一定涨？” 应该会涨。 离线和在线不同。 MSE 只看动作接近专家，在线成功还取决于闭环误差累积、contact dynamics、视觉状态分布偏移和成功判定。
