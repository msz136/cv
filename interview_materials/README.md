# 面试项目材料包

创建日期：2026-07-07

这个目录存放简历背后的项目面试材料，不修改简历正文。每个 HTML 文件都可以直接用浏览器打开，内容包括：

- 项目一句话定位和 2-3 分钟口述稿
- 机制解释和公式化表达
- 真实性边界与证据边界
- 简历 bullet 三档
- 高频追问、深入追问和回答分层
- 补证据 checklist

## 使用建议

- 面试前优先背每页的“短答案”和“2-3 分钟口述稿”。
- 技术深挖前看“机制拆解”和“追问树”。
- 被质疑指标或贡献边界时，用“真实性边界”和“回答分层”防守。
- 后续补实验或补证据时，从每页的 checklist 里挑最高价值项。
