总口径

简历主线面试时要讲出的设计感边界防线
机器人任务表示与工具调用训练 把机器人集群控制中的高层失败模式抽象为可训练 schema / reward / eval，再通过 SFT/GRPO 学习可验证的 action/tool 语义。 tool accuracy 是真实任务执行的前置代理，不等价于真实机器人成功率。
VLM Grounding 与 OPD 按 Motivation / Hypothesis / Method 拆开数据分布、teacher 互补性、输出格式和 OPD，不把最终指标单因果归给某一项。 没有完整 ablation 时，不把提升单因果归于 OPD；只能说“证据支持该机制解释”。
VLA / WAM / UWM 复现与改造 重点讲动作表示、训练目标、评估协议分别对应什么开放问题，而不是“我跑通了框架”。 仿真 benchmark 不覆盖真实机器人全部泛化、视觉扰动、延迟和任务组合复杂度。

证据边界

  • 本地证据：当前简历 HTML、resume_restructure_plan.md、用户提供的训练/评估指标与项目事实。
  • 公开背景：LIBERO、OpenPI、Cosmos Policy、RoboCasa、UWM 等公开论文/仓库/文档，用于解释方法上下文，不替代本地证据。
  • 面试表达：可以讲机制假设、设计取舍和风险边界；不要把代理指标说成真实机器人任务成功率。
