4. 首轮建议队列

第一轮只练 5 题，覆盖模型、RL、机器人和闭环：

  1. VLA-FND-030：observation / state / proprioception / action。
  2. VLA-FND-012：attention 为什么除以 \(\sqrt{d_k}\)。
  3. VLA-FND-021：MDP 五元组如何映射机器人任务。
  4. VLA-FND-029：offline MSE 为什么不等于 online success。
  5. VLA-FND-037：控制频率、推理延迟和 action chunk。

训练时一次只问一个问题；每题更新 Substance、Structure、Relevance、Credibility、Differentiation，并把暴露的风险回写到 knowledge/evidence。

5. 入库规则

  • ID 唯一；同义题合并。
  • 有来源、短答案、项目 hook、追问和易错点。
  • 普通答案目标 ≤350 字；代码题按单独规则审查。
  • 题目生成后默认 unseen。
  • 未经事实审查的题卡 review verdict 保持 WARN。
