VLA 真实口述 Drill Queue

状态：queued / no_candidate_answers / no_mastery_changes 更新日期：2026-07-21 用途：把已有题卡转成一次只问一题的口述队列。这里不记录候选人答案，不替代 coaching_state.md；第一次真实回答后，才创建正式训练状态。

1. 执行协议

每次只取队首一题，候选人先回答，之后才进入反馈和下一题。回答时优先给出：

  1. 任务/问题与输入输出边界；
  2. 自己实际负责的接口、决策或验证动作；
  3. 机制链与 trade-off；
  4. 可定位证据、协议和分母；
  5. 当前不能证明的内容与下一步补证。

没有 raw artifact 时，答案必须明确使用 inference 或 unverified，不能用 Git author、文件名、上游论文、summary 或配置路径代替 ownership。

3. 单题评分卡（回答后使用）

每个维度 1–5 分；未回答时不填分数：

维度1 分3 分5 分
Substance只有名词能解释主要机制能补公式/实现/反例与 trade-off
Structure叙述跳跃有问题→方案→结果证据链与追问顺序清晰
Relevance泛泛讲论文对齐题目只保留与该项目/岗位相关的细节
Credibility无证据或越界能指出部分缺口每个 claim 都绑定 artifact、protocol 或明确的 unknown
Differentiation像模板答案有项目接口细节能说清个人决策、失败转折与下一步实验

反馈顺序固定为：What I Heard → What Is Working → Gaps To Close → Priority Move → Next Step。第一次回答前，不创建 coaching state，也不修改题卡 review JSON。

4. 回答提交格式

候选人每次只需发送一题的自然口述文字，建议附带：

Stable ID: PROJ-WAM-001
回答：……
我最不确定的点：……（可选）

收到后才记录 transcript、五维评分、证据缺口和下一题；如果回答中出现无法由仓库证据支持的数字，会先降级 claim，再给补证建议。
