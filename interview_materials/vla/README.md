## 目录职责

| 目录 | 职责 | 不应包含 |
| --- | --- | --- |
| `sources/` | GitHub、论文、官方文档、benchmark 与题源审计 | 未核实答案正文 |
| `knowledge/` | 可学习的深度知识页：直觉、公式、伪代码、实现映射、trade-off | 个人项目的无证据强 claim |
| `questions/` | 可折叠自测题卡：短答案、易错点、追问、掌握状态 | 长篇教程式重复内容 |
| `evidence/` | 简历 claim、个人贡献、代码/日志/指标和风险边界 | 通用八股正文 |
| `practice/` | 逐题训练、模拟面试、复盘和状态 | 未经练习就标记为掌握 |
