## 实习条目

Embodied Agent Harness：设计并实现机器人 embodied agent harness，将底层控制能力抽象为模型可调用的 skills，以统一的任务与执行接口贯通自然语言目标、任务规划与物理执行，支持 agent 分解任务、调用技能并根据执行反馈推进后续行动。在此基础上，针对长时动作执行期间持续到来的用户交互，引入任务中断、切换与恢复机制，使机器人在执行任务时仍可响应新指令，并保留原任务的执行上下文；进一步通过 subagent 分工与任务级执行权管理，支持多机器人、多会话下的任务协作。

Embodied Agent Model：面向具身 Agent 的任务决策与工具使用，搭建基于 Qwen3-VL-32B 的后训练流程，将机器人技能接口与执行约束转化为模型的学习目标。在 SFT 初始化基础上，设计结合工具 schema、技能选择、关键参数及机器人作用域的可验证奖励，开展 GRPO 优化；在任务指令驱动的工具选择测试中，工具选择有效率较 base model 相对提升 74.5%。

## 项目条目

Embodied Visual Grounding：面向视觉语义理解中的目标定位与空间理解，基于 SFT 构建覆盖物体定位、区域理解、空间关系、点选定位及通用理解的多领域 expert models，通过冷启动与多教师 OPD 将各领域能力整合到统一的 8B VLM，支持从自然语言目标与空间描述到图像位置的映射。在独立测试集的框定位子集上，Acc@0.5 较 base model 相对提升 28.2%，点选定位 Hit@100 达 87.3%。

VLA 策略训练与闭环仿真：基于 OpenPI，在沐曦 C500／MACA 平台开展视觉—语言—动作策略的微调与适配，并在 LIBERO 机器人操作任务中进行闭环仿真 rollout，使策略根据连续视觉观测生成并执行动作，结合任务成功率与执行轨迹评估策略表现。
